It's been forever since I actually started making this personal website! I thought I would get started on it sooner, but I was dying in trying to understand the frameworks people build websites with.

Biggest lesson learnt:
- Web Dev does't equal to making websites!

Web dev people aren't just interested in making fancy looking websites, they want useful websites, so like websites that make it scalable with lots of repeated assets, websites that are intuitive to use so anyone can pick it up.


Like, going through MIT IAP... it's not really trying to talk about how to make fancy looking things, it's more trying to explain the underlying interactions of say, like what HTML, CSS, Javascript's job is doing together, then what is the point of something like React on top of all this.

Then you are 'sort of' done with front end (ugly but functional), and then how do we actually connect it with backend servers, how we call external API services, how it connects with databases...


Like, guys, I'm just here to try to make some cool looking frontend website... that's it...
